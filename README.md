
# 📊 Sales Performance Analysis Dashboard (Python)

## 📌 Project Overview
This project focuses on analyzing retail sales data using Python to evaluate business performance. The analysis includes data cleaning, KPI calculation, trend analysis, and visualization to derive meaningful business insights that support data-driven decision-making.

---

## 🎯 Objectives
- Clean and preprocess raw sales data
- Track key performance indicators (KPIs)
- Analyze sales trends over time
- Identify top-performing regions, categories, and products
- Generate actionable business insights using visualizations

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📂 Dataset
- **Source:** Superstore Sales Dataset
- **Type:** Retail transactional data
- **Key Fields:** Order Date, Sales, Profit, Category, Region, Product Name

---

## 🔍 Key KPIs Tracked
- Total Sales
- Total Profit
- Profit Margin
- Average Order Value
- Monthly Sales Trend
- Region-wise Sales Performance
- Category-wise Profitability

---

## 📈 Analysis Performed
- Data cleaning (duplicates, missing values, date formatting)
- Feature engineering (Year, Month, Profit Margin)
- Exploratory Data Analysis (EDA)
- Trend analysis using line charts
- Comparative analysis using bar charts

---

## 📊 Visualizations
The project includes visualizations such as:
- Monthly sales trend
- Sales by region
- Top 5 products by sales
- Profit by category

All charts are generated using **Matplotlib** and saved for documentation.

---

## 🧠 Key Insights
- Certain regions contribute higher sales but lower profit margins
- Sales show seasonal trends with peaks during specific months
- Some product categories generate high revenue but low profitability
- A small number of products contribute significantly to total sales
